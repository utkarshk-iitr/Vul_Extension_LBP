\begin{abstract}
% \addchaptertocentry{\abstractname}
Detecting software vulnerabilities at an early stage is important for improving the security and reliability of software systems. However, traditional vulnerability detection methods often struggle to accurately identify insecure code and provide meaningful guidance to developers. This thesis presents a vulnerability detection framework for C/C++ source code that combines deep learning techniques with Large Language Models to support automated vulnerability detection, explanation, and fix suggestion generation.

The proposed system integrates machine learning–based code analysis and a Retrieval-Augmented Generation (RAG) mechanism that utilizes vulnerability knowledge sources to improve contextual understanding and detection accuracy. The framework is designed to support efficient real-time analysis and provide developer-friendly security recommendations. Experimental evaluation on real-world C/C++ code samples demonstrates improved vulnerability detection performance and effective localization of vulnerable code segments.

\end{abstract}
